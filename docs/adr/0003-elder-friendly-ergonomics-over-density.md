# Elder-friendly ergonomics over UI density

The primary user demographic for the Atharvashirsha recitation is older devotees (50+ years) chanting during morning prayers or in temple settings. We decided to prioritize large touch targets (60–76px), explicit text labels ("Read", "TV", "Start again") over ambiguous icons, and 2px high-contrast borders, moving secondary settings into a bottom sheet.

## Considered Options

- **Dense toolbar with icon-only glyphs (☰, ⛶, ↺)**: Rejected because older users struggled to distinguish icon functions and experienced accidental miss-taps.
- **Permanent on-screen configuration controls**: Rejected because displaying script, speed, highlight, and calibration toggles simultaneously cluttered the text area on mobile displays.

## Consequences

- Transport controls are effortlessly reachable and readable at arm's length without reading glasses.
- Everyday chanting controls remain uncluttered, while detailed configuration stays accessible within the bottom sheet.
