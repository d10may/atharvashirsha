# Bhajam · भजन व स्तोत्र संग्रह

**Bhajam** is an interactive recitation and walkthrough companion with real-time word tracking, tempo calibration, Devanagari / Roman script options, and full-screen TV display mode.

## Available Walkthroughs

- **[Bhajam Home](index.html)**: Main directory listing all hymns, aartis, and stotras.
- **[श्री गणपति अथर्वशीर्षम् (Ganapati Atharvashirsha)](atharvashirsha.html)**: 10 verses with recitation playback and word-by-word tracking.
- **[श्री गायत्री माता की आरती (Mata Gayatri Aarti)](gayatri-aarti.html)**: 11 stanzas with interactive player and Roman transliteration.

## Features
- **Word & Phrase Tracking**: Automatic cadence and tempo progression based on Sanskrit prosody (mātrās).
- **Dual Script Support**: Devanagari, Roman transliteration, or both simultaneously.
- **TV / Projector Mode**: Large display formatting designed for gatherings and temple screens.
- **Auspicious Vedic Theming**: Sacred Chandan (sandalwood) parchment light mode and deep Sanctum Sanctorum dark mode.
- **Elder-Friendly Ergonomics**: 60–76px high-contrast touch targets, generous line-height, and zero external audio dependencies.
